# Проект Detect_Rust: Универсальное скоростное ядро распознавания и трекинга

## 1. Миссия и концепция системы
Создание **высокоскоростной, универсальной, платформо-независимой системы (ядра) распознавания и сопровождения объектов** на языке **Rust**.

- **GitHub репозиторий:** [https://github.com/korshun199/Detect_Rust](https://github.com/korshun199/Detect_Rust)
- **SSH Remote:** `git@github.com:korshun199/Detect_Rust.git`

### Два ключевых режима работы системы:
1. **Режим 1: Нейросетевой (AI Detection & Reconnaissance)**
   - **Цепочка:** Сканирование сектора $\to$ Распознавание ИИ $\to$ Автозахват $\to$ Отображение прицела на OSD.
   - **Назначение:** Воздушное и наземное наблюдение, автоматический мониторинг, поиск дронов/техники/людей без участия оператора.
2. **Режим 2: Оптический трекер (Pure Optical Tracking & Motor Guidance)**
   - **Цепочка:** Захват цели $\to$ Запоминание микротекстуры объекта $\to$ Высокоскоростное слежение (200+ FPS) $\to$ ПИД-управление рулями и двигателями (доводка на цель в STM32).
   - **Назначение:** Терминальное наведение дрона-перехватчика/камикадзе на скорости с минимальной задержкой (~1 мс). Нейросеть в этом режиме отключена для максимального сбережения ресурсов и питания.

Система проектируется как фундаментальное модульное ядро, способное масштабироваться и работать на любом типе оборудования:
- От ультра-маломощных микроконтроллеров и встраиваемых чипов (STM32, ESP32, в перспективе даже архитектур класса Z80 с фиксированной точкой);
- До одноплатных компьютеров (Raspberry Pi 4, Orange Pi), мобильных устройств и автоэлектроники;
- И вплоть до мощных рабочих станций (Linux Ubuntu, Windows) и серверных кластеров со стойками GPU (NVIDIA A100/H100).

Прикладное решение для дрона «Веста» (DeliveryDrone на Raspberry Pi 4 с камерой IMX327 и полетником STM32) является **первым целевым адаптером** этого универсального ядра.

### Лабораторный аппаратно-измерительный комплекс:
1. **STM32 & ESP32:** Целевые микроконтроллеры для низкоуровневых интерфейсов, полетных задач, приводов и радиотелеметрии (ExpressLRS 433/915 МГц).
2. **Цифровой логический анализатор:** Аппаратная верификация таймингов, протоколов UART, SPI, I2C, импульсов PPM/PWM/SBUS.
3. **USB-UART переходники (CH340 / CH341 / FTDI / CP2102):** Снятие логов и потоков данных на скоростях до 921600+ бод.
4. **ST-Link (V2 / V3):** Внутрисхемная отладка и прошивка STM32 по SWD.
5. **Лабораторное электронное оснащение:** Осциллограф, ЛБП, преобразователи питания, батарейные сборки.

## 3. Архитектура проекта: Cargo Workspace

Проект структурируется на независимые крейты, где алгоритмическое ядро полностью отвязано от периферии:

```
Detect_Rust/
├── Cargo.toml                  # Корневой Workspace манифест
├── PROJECT.md                  # Главный архитектурный документ и паспорт системы
├── HOW_IT_WORKS.md             # РУКОВОДСТВО ПРОСТЫМИ СЛОВАМИ (для заказчика и презентаций)
├── AGENTS.md                   # Правила проекта и регламент взаимодействия
├── GEMINI.md                   # Память реверса и золотые правила Машеньки
├── README.md                   # Открытое нейтральное описание для GitHub
├── settings.json               # ЕДИНЫЙ ИСТОЧНИК НАСТРОЕК (видео, пороги, OSD, PID)
├── run                         # ЕДИНЫЙ ИСПОЛНЯЕМЫЙ СКРИПТ для Олежки (вывод + tee в logs/)
├── logs/                       # ЕДИНЫЙ КАТАЛОГ ВСЕХ ЛОГОВ (latest.log + timestamp.log)
│
├── crates/
│   ├── detect-core/            # ЧИСТОЕ АЛГОРИТМИЧЕСКОЕ ЯДРО
│   │   ├── Cargo.toml          # no_std совместимость, zero runtime overhead
│   │   └── src/
│   │       ├── lib.rs          # Публичные трейты: Tracker, Detector, FrameView, Target
│   │       ├── kcf.rs          # Быстрый корреляционный трекер
│   │       ├── math.rs         # Матричные операции, fixed-point / float, SIMD
│   │       └── control/        # ПИД-регуляторы и цифровые IIR-фильтры
│   │
│   ├── detect-compute/         # ВЫЧИСЛИТЕЛЬНЫЕ БЭКЕНДЫ
│   │   ├── Cargo.toml
│   │   └── src/                # CPU Fallback, SIMD (NEON / AVX), GPU/NPU бэкенды
│   │
│   └── detect-ffi/             # C-СОВМЕСТИМЫЙ ИНТЕРФЕЙС (C-ABI)
│       ├── Cargo.toml          # crate-type = ["cdylib", "staticlib"]
│       └── src/                # Экспорт функций для C, C++, Python, C#, Windows, Android
│
└── apps/
    ├── delivery-drone/         # БОРТОВОЕ ПРИЛОЖЕНИЕ ДЛЯ ДРОНА «ВЕСТА»
    │   ├── Cargo.toml
    │   └── src/
    │       ├── main.rs         # Точка входа на Raspberry Pi 4
    │       ├── pipeline/       # GStreamer: libcamerasrc (IMX327) + kmssink PAL (sync=false)
    │       ├── protocol/       # UART 921600: COBS + Postcard протокол полетника STM32
    │       ├── osd/            # Отрисовка сетки, рамки захвата, батареи и Failsafe
    │       └── config.rs       # Загрузка JSON5 конфигурации дрона
    │
    └── desktop-bench/          # ТЕСТОВЫЙ СТЕНД ДЛЯ НОУТБУКА (Linux / Windows)
        ├── Cargo.toml
        └── src/                # Бенчмарки, профилирование FPS, синтетические тесты видео
```
